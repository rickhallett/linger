# Linger changelog

## 0.1.0

First independent Linger release: live and replay inspection, recorded input/output, local command documentation, optional asynchronous Mercury interpretation, pattern library, persistent learning states and a command field guide.

macOS archives cover Apple Silicon and Intel. Runtime tags use `runtime-vX.Y.Z`. The website deploys from main without releases.

The retained Zoetrope changelog is in [docs/UPSTREAM-CHANGELOG.md](docs/UPSTREAM-CHANGELOG.md).
